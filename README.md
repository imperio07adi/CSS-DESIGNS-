# 🎨 StyleCraft

Welcome to **Creative CSS Designs** — a curated collection of experimental, creative user interface components built entirely with **HTML** and **CSS**. No JavaScript required (unless for interactivity), just pure style, structure, and imagination.

---

## 🌟 What is This?

This website is a **playground for CSS lovers and UI tinkerers**. It showcases animated buttons, loaders, layouts, page transitions, dividers, and more — all handcrafted using modern CSS techniques like Flexbox, Grid, Transitions, and Custom Animations.

> 💡 _It's not just a gallery — it's a spark of inspiration for your next front-end experiment._

---


## 📂 Features

- 🎨 Unique UI Components & Animations  
- ✨ Creative Layouts and Page Dividers  
- 🧪 100% HTML & CSS Only – Lightweight and Fast  
- 📱 Fully Responsive & Mobile Friendly  
- 🌈 CSS Gradients, Keyframes, and Shadows Galore

---

## 🛠️ Built With

- **HTML5**
- **Tailwind CSS**
- **Custom CSS animations**
- Optional: Vanilla JavaScript for minimal interactivity (e.g., navbar toggle)
